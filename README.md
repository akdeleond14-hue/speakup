# Speak Up

App personal de Ana Karina para practicar inglés hablado con personajes 3D, inspirada en las funciones de LingoLooper (clon de funciones, con contenido propio). Uso personal, no comercial.

- Abre en Safari (Mac o iPhone). La primera vez pide la clave gratuita de Google AI Studio y la guarda solo en el navegador.
- Conversación por voz en tiempo real: Gemini Live API (plan gratuito).
- Correcciones, traducción, ayuda y resumen: Gemini (plan gratuito).
- Personajes 3D: [TalkingHead](https://github.com/met4citizen/TalkingHead) (MIT) con sus avatares de ejemplo (uso no comercial).
- Progreso guardado en el navegador; se pasa entre dispositivos con el código de Ajustes.

En el plan gratuito de Google, las conversaciones pueden usarse para mejorar sus productos.

La carpeta `replica/` tiene el recon y la arquitectura del proyecto.
